Final spec — three places proficiency lives:
  • MOS dropdown (closed): HEAVY GUNNER · 78%. Precise number lives on the role selector. When open (Frame 5) it shows every MOS Reyes has trained with stars + tier + % so you can compare before switching.
  • Pill (closed): ★★★☆☆ VETERAN ▸. At-a-glance rank insignia. Stars accrue at 20% thresholds (S5 scheme). Pill carries the rank, dropdown carries the number — no info double-up.
  • Pill expand (Frame 4): yellow panel slides in showing WHAT IT SCALES (×0.78 to gear, +31% effective range, −13% reload, −18% recoil) and the TIER LADDER (where you are, what's next).
Star threshold mapping (S5):
  • 0–19% → ☆☆☆☆☆ TRAINEE
  • 20–39% → ★☆☆☆☆ RECRUIT
  • 40–59% → ★★☆☆☆ REGULAR (Anderson 50%)
  • 60–79% → ★★★☆☆ VETERAN (Reyes 78%)
  • 80–99% → ★★★★☆ MASTER (Carter 85%)
  • 100% → ★★★★★ MASTER (5th star is the mastery flourish)
Tap-to-expand pattern:
  • Default row stays clean — just the headline output (SIGHT, HP, RELOAD, SPD).
  • Tap any row to reveal the full breakdown inline. Tap again (or another row) to collapse.
  • Expanded rows get a soft green tint + a left-rule that visually groups the detail under its parent row.
  • Chevron ▸ rotates to ▾ when expanded so the affordance is obvious.
  • Each detail line shows: effect name, number, and a plain-English note. Unimplemented effects are italicized as "pending" so we don't over-promise.
What each physical actually drives (Frame 2's REF expansion is verbatim from the code):
  • VIS → sight range, future crit chance bonus.
  • STR → HP max, recoil reduction (stability under fire).
  • REF → reload speed (−%), recoil settle, vehicle turn rate. Not target acquisition (that's Awareness/Initiative).
  • END → movement speed, suppression resistance.
Implementation notes:
  • The expand state is per-row, not per-stat — only one row open at a time keeps the dossier compact.
  • Mobile-friendly: full row is the tap target (~44px tall once padding lands).
  • The wounded HP styling (yellow current + dim max) reuses the same row, no special-case layout.
