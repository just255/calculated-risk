Customization sketch (not built yet)

Path I'd take when you're ready:
1. Built-in library — the picked battle + menu cursors ship as defaults. Cursor styles live as inline SVG strings keyed by name in cursor-library.js.
2. Settings tab — under Settings, add a Cursors sub-tab with two pickers (Menu, Battle). Each picker shows a swatch grid like above; selection writes to Game.settings.cursors = {menu, battle} and persists to localStorage.
3. CSS variable plumbing — a tiny module reads Game.settings.cursors on load + setting change and updates two CSS custom properties (--cursor-menu, --cursor-battle). All rules use those vars so the switch is instant, no reload.
4. Custom upload — an "Add custom" button accepts an SVG paste or file upload, validates it (size, viewBox, no scripts), stores it in the user's settings, and adds it to their picker. Library entries are read-only; user entries are editable / deletable.
5. Share — export-as-string + import-from-string round-trips a single cursor, so a community can swap designs.
Tell me which of B1/B2 you want for battle, which of M1–M4 you want for menus, and whether you want the customization feature wired now or filed as a follow-up.
