Mobile layout (landscape default):
  • Expanded panel takes the bottom 60% of the screen — leaves enough room for the map + HUD on top.
  • 3-column body: LOADOUTS / SQUAD / POOL. Drawer slides over the right side when a unit is selected (overlays POOL).
  • Header bar holds the zone name, UNIT/CMD toggle, Collapse arrow, and the DEPLOY button (always visible).
  • Bottom strip is always-present — switching zones is a single tap, not a navigation.
What stays on canvas:
  • The battle map itself (terrain, unit sprites).
  • In-world zone highlights — the red gradient down the sides of the selected zone, dashed dividers between zones.
  • The minimap (already its own canvas).
  • Inside HTML containers: small canvases for the formation preview thumbnails (fmt-mini + squad-fmt-preview) and the radar chart in the drawer (drawer-radar). These mount once and only redraw when their inputs change — no per-frame redraw.
Action wiring (preview):
  • data-action="dp-zone" · zone chip click → set selected zone, expand panel
  • data-action="dp-collapse" · collapse the expanded panel back to just the strip
  • data-action="dp-preset" · pick a preset loadout
  • data-action="dp-formation" · change formation (or use <select onchange>)
  • data-action="dp-pool-tab" · switch BARRACKS / MOTOR POOL
  • data-action="dp-pool-select" · click a pool row → opens drawer
  • data-action="dp-pool-add" · click the + → add to current zone's lineup
  • data-action="dp-lineup-remove" · pull a unit out of the lineup
  • data-action="dp-mode" · UNIT / CMD toggle
  • data-action="dp-deploy" · confirm deployment, sets b.deployReady.blue = true
Open questions for sign-off:
  • Drawer position — overlay the POOL column from the right (as drawn) or become a 4th column when there's screen room?
  • Drawer auto-open on lineup row click, or only on pool row click? Both feel reasonable.
  • Should we add an "Auto-balance" button somewhere (push reserves into zones in a sane default)?
  • Portrait phones — should the panel become a full-screen modal with vertical scroll, or stack columns?
