Division of labor:
  • MOS dropdown — precise value, per role. The selector knows about every MOS this soldier has trained, with their respective proficiencies. Lets you compare before switching.
  • Header pill — at-a-glance rank for the currently-selected MOS. Stars say where on the ladder, tier name names the rank.
  • Expand panel — what proficiency unlocks (×0.78 to gear, +31% effective range, etc.) + tier ladder visual + delta to next tier.
F3 — Compact dropdown format (HEAVY GUNNER · 78%):
  • Pro: cleanest. No repetition with the pill — the dropdown supplies the precise number, pill supplies the rank.
  • Pro: tighter row, easier to fit on mobile.
  • Con: dropdown options (in open state) still need tier name for richer comparison.
F4 — Verbose dropdown format (HEAVY GUNNER · VETERAN · 78%):
  • Pro: dropdown self-contained — if you only ever read the dropdown, you have full info.
  • Con: VETERAN appears twice on the same row (in dropdown and pill). Lower-grade fighting.
  • Con: longer dropdown chip, less room for the pill.
My take:
  • F3 (compact) for the closed selector — number in dropdown, rank on pill, no double-up.
  • Open dropdown shows full per-MOS rank (F2 layout) — stars, tier, %, current marker. This is the high-information state where comparison matters.
  • Pill stays clean: ★★★☆☆ VETERAN ▸. Tap to expand for what proficiency drives.
