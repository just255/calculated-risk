# Particle Sprite Prompts (256px Pixel Art)

Small particle sprites for scatter effects. These have `noCollision: true` so they layer freely.

Generate 3 images from each prompt for variants.


## Post-Processing

See [imagemagick.md](imagemagick.md) for resize instructions.

```bash
magick input.png -filter point -resize 256x256 output.png
```
