# Tree Sprite Prompts (128px Pixel Art)

Generate at 1024x1024 (or AI's native size), then resize to 128x128 in GIMP using NoHalo/LoHalo interpolation.

**Structure:** 4 tree types × 5 stages = 20 sprites
- **Types:** Oak, Pine, Birch, Willow
- **Stages:** Young, Old, Transitional, Dead Young, Dead Old

---

## OAK

### Oak - Young

```
Single young oak tree viewed from directly above, modern pixel art style with chunky defined pixels. Transparent PNG with alpha channel.

- One young oak tree, centered
- STRICTLY top-down view, camera PERFECTLY perpendicular to ground, exactly 90 degrees, NO angle or tilt, no trunk visible
- Sparse irregular canopy with asymmetrical lobed edges, NOT perfectly round
- Organic shape with natural variation, some branches extend further than others
- Gaps in canopy where sky/transparency shows through
- Small crown, branches not fully filled in
- Muted desaturated tones - subdued military color palette
- NOT vibrant
- Light source directly overhead (noon)
- EXACT COLOR PALETTE (use only these colors):
  - Shadows: #1a2a1a, #2a3a2a (nearly black-green)
  - Midtones: #4a6a3a, #5a7a4a (olive-green)
  - Highlights: #6a8a5a, #7a9a6a (lighter olive)
- STRONG CONTRAST: Very deep dark shadows between leaf clusters and under canopy edges, brighter highlights on sun-facing surfaces
- Shadows should be nearly black-green, not washed out
- Chunky pixel art aesthetic, not photorealistic
- Tree fills 45% of frame

Transparent PNG, no checkered background. Make sure that everything that is not the tree or leaves is an alpha channel.
```
